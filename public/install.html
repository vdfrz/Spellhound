Install Spellhound in Word

This is the private pilot install guide. Use a blank test document in a dedicated Word profile.

  1. Download the Word add-in manifest from this pilot host.
  2. In Word for the web, choose Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in, then select the XML file. If your organization blocks uploads, ask your Microsoft 365 administrator to assign this manifest to the pilot group.
  3. On a Mac, you can instead put the XML in Word’s ~/Library/Containers/com.microsoft.Word/Data/Documents/wef folder, restart Word, and select Spellhound under Home → Add-ins.
  4. Choose Open Spellhound, sign in with Publik in your browser, and return to this pane to choose your AI provider.

Iris can walk you through these steps. Close private documents first. Complete sign-in and any payment yourself; never give Iris a claim link, password or provider key.
