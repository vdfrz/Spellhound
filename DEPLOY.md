# Deploying Spellhound

The intended production host is Publik. Its public hosted listing requires an already deployed HTTPS URL. Confirm compute, private persistent storage and the identity contract before publishing. The listing itself does not provision a server.

Build and run the service as described in the README. Never use a personal inference key as the app token. A public sign-in test needs a listing-specific app token and a user completing the browser claim. Exercise two distinct installations, revoked access, sign-out, provider selection, usage consent and Office cookie compatibility before submitting the Word manifest.
